# Medical Cost — Health Cost (ML Project)

Projet de Machine Learning de bout en bout (régression) :
EDA → preprocessing → modèles → API → tests → CI (GitHub Actions) → slides

## Structure
- `notebooks/` : EDA + modeling
- `src/` : scripts (train / evaluate / predict)
- `api/` : FastAPI (`app.py`)
- `tests/` : tests pytest
- `.github/workflows/` : CI
